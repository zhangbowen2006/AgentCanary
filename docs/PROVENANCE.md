# 来源、独立性与 AI 辅助披露

AgentCanary 是 zhangbowen2006 为十月赛新建的独立项目，原始提交记录始于 2026-10-19。没有把此前项目改名提交，也没有移植或复制第三方项目的核心实现。

本账号此前公开的 MoonBVHKit（空间加速结构）、MoonKeyguard（编辑器快捷键契约）、MoonBitTargetParity（跨后端行为契约）与本项目的输入格式、运行状态、算法目标和核心代码不同。本项目新增的独立贡献是 artifact 敏感标签与来源追踪、限时单次审批生命周期、观察成本窗口、确定性策略对比，以及每调用完整断言的回归用例集。

## 使用的组件

| 组件 / 材料 | 来源与用途 | 许可 / 处理 |
| --- | --- | --- |
| MoonBit 标准库与运行时 | moonbitlang/core，JSON、集合、基础类型 | 上游 Apache-2.0；通过工具链依赖，无源码复制 |
| Node.js 标准库 | 文件、子进程启动构建、HTTP 本地预览、测试 | 宿主依赖，无第三方 npm 包 |

| 合成轨迹和用例 | 本仓库人工构造，example.invalid 域名 | MIT；无真实客户数据、API Key 或外部素材 |
| 图标与界面 | 本仓库原创 SVG / CSS | MIT；无需字体、图片、追踪服务 CDN |
| 截图 | 本项目本地界面实际运行截图 | MIT；不含真实个人数据 |

Playwright 用于本地浏览器检查，w64devkit 用于本机 Native 验证，均仅为开发环境工具，不打包进发布库。核心算法未使用这些工具的代码。工具下载、缓存和辅助脚本位于被忽略的 work 目录。

## AI 参与和参赛者责任

本项目的选题细化、MoonBit 代码、测试、适配器、界面和文档由 AI 辅助完成；不应将其描述为完全手写。测试结果只能证明覆盖的行为，不能证明不存在缺陷。参赛者应阅读 SEMANTICS、ARCHITECTURE、输入样例和核心实现，能够解释状态不变量、数据流可信边界、窗口端点及审批消费规则，并在正式申报前确认自己理解并愿意维护这些结果。

不存在已验证的生产用户、真实攻击检出率或独立安全审计。当前演示和基准使用合成数据；这些限制已公开。后续竞争力提升应来自真实集成与用户反馈，不通过补造提交历史、虚构下载量或堆叠无意义代码获得。
