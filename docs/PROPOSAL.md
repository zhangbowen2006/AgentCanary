# AgentCanary · 十月新项目申报书

- 参赛者 / GitHub ID：zhangbowen2006。
- 仓库：https://github.com/zhangbowen2006/AgentCanary
- 定位：原创 MoonBit 库，离线回放 AI 工具调用记录，进行策略审计与策略变更回归测试。
- 真实需求：Agent 的单次工具参数检查无法解释跨调用的数据外发、审批复用和累计预算问题；策略升级也容易误拦正常流程。
- 新增价值：按 artifact 依赖传播敏感标签及来源，使用与工具、资源、会话绑定的限时单次审批；对同一观察记录运行两套策略，输出新增拦截、解除拦截和证据。
- 从零实现：独立仓库、独立核心代码；与本人既有 BVH、快捷键契约和跨后端比较项目的定位、API、算法与输入模型不同。
- 技术路线：严格 JSON / JSONL 输入 → 轨迹有效性检查 → 会话隔离的状态回放 → 规则判定与因果证据 → 结构化报告 / 策略差异。
- 计划功能：工具与资源匹配、默认拒绝、敏感标签传播、审批与撤销、累计和滑动窗口预算、调用频率、前置步骤、JSON 报告、回归断言。
- 交付：公开 MIT 仓库、Mooncakes 包、MoonBit API 与可运行示例、Node CLI、浏览器交互演示、中英文使用文档、CI。
- 验证：正常与攻击轨迹、格式错误、会话交叉、边界时刻、预算精度、审批复用、未知 artifact、确定性和跨后端测试。
- 范围：本版本分析已记录的工具事件，输出调用级策略判断；不执行工具、不认证审批者、不判定自然语言攻击，也不模拟被拦截后 Agent 的后续行为。
- 来源：原创核心，无移植上游；依赖 MoonBit 标准库。样例使用人工构造的虚构数据，AI 辅助开发范围和技术边界在仓库公开说明。
- 完成标准：严格检查、格式、测试和构建通过；README 命令可复现；核心申报功能有测试及演示证据；公开默认分支与 Mooncakes 发布可查。
